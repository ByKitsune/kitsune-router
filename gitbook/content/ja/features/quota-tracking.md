# クォータと使用量

使用量をローカル記録し、上流が対応する枠・リセット情報を表示します。使用量概算、利用枠、請求書は別のものです。

## データの見方

- ルート別の実測 input/output/cache を使い、欠測値をゼロにしません。
- 枠はアカウント・モデル・サービス・期間別の場合があります。プローブ失敗は新枠や無効アカウントの証明ではありません。
- **不明な価格は無料ではありません。** 既知小計と未価格件数は完全な総額ではありません。
- 実際の速度階層は要求と異なる場合があります。契約クレジットは API 米ドル請求ではありません。[速度](https://github.com/ByKitsune/kitsune-router/blob/master/docs/PROCESSING-SPEED.md)。
- 再試行は課金される場合があり、クライアントの取消で上流課金停止は証明できません。トークン上限は総金額予算ではありません。

## ダッシュボードの更新

2026年10月29日のソース変更では、使用量の確定後に選択期間の統計とグラフをまとめて再取得します。接続・再接続時にも更新します。旧サーバーでは集計値や内訳の変化を更新の手がかりにしますが、全期間のデータで選択期間の値を置き換えることはありません。更新前から開いていたタブは再読み込みして新しいクライアントを使ってください。

再取得に失敗した場合は最後に取得できたデータと、そのデータが対象とする期間を表示します。再試行ボタンを使い、セッション切れの場合は再ログインしてください。時間の経過だけでは自動更新されないため、期間を切り替えるかページを再読み込みしてください。旧ストリームでは比較対象の集計値と内訳がすべて同じ場合、変化を検出できません。本番で起きた元の問題の原因は未確認です。

## 価格の対象範囲

提供元を限定しない共通料金の廃止により、別製品の料金を誤用しにくくなりますが、従来は数値が出ていた一部のルートが価格不明になります。models.dev の参照値を入出力の概算に使えるのは、テキスト専用の提供元・モデルの正確な組み合わせ16件に限られ、観測から24時間以内です。現在の期限は **2026-10-29 18:11:32.422 UTC** で、自動更新はありません。期限後は別途確認されたルート別料金または運用者の上書きを使用できます。記録済み費用は再計算されず、参照値は請求書ではありません。

OpenCode が返す `usage.cost` と Go 利用枠のフィールドは、使用量台帳にまだ保存されません。これらの金額は提供元の画面で確認してください。利用枠は現金での請求額とは異なります。

## 保存と監視

設定・使用量は `${DATA_DIR}/db/data.sqlite` を共有します。`usage.json`/`db.json` は旧移行入力です。絶対パスを使い、停止後に秘密・auth・証明書を含め全体バックアップします。[運用](https://github.com/ByKitsune/kitsune-router/blob/master/docs/OPERATIONS.md)。

認証付き `/api/metrics` の現行出力を調べてから監視します。移動期間スナップショットへ `rate()`/`increase()` を盲用しないでください。`/api/health` や過去のテスト数は上流権限・現行版を証明しません。圧縮に固定削減率はなく、実料金は上流請求で確認してください。
