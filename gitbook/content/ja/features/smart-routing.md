# スマートルーティング

Kitsune Router は**利用者が設定した**モデル・アカウントへルーティングします。サブスクリプション→低価格→無料の順序、ByKitsune 優先やアカウントは強制しません。

## 選択とフォールバック

直接モデル要求はそのルートを選びます。コンボ名は設定済みメンバー・戦略へ展開され、そのプロバイダー内でアカウントを選びます。直接モデルに未設定の全体フォールバックが自動追加されるわけではありません。

```text
my-route を要求
  → 設定したメンバー A → 利用可能アカウント
  → 許可された再試行・フォールバック
  → メンバー B、または正確な終了エラー
```

先に `my-route` を作成し、有効モデルを能力・プライバシー・遅延・費用で選んでください。カテゴリは順序を決めません。[コンボ](/ja/features/combos/)。

不明な枠は無制限ではありません。不正要求・キャンセルでアカウントを使い切らず、有料出力上限を黙って増やしたり文書・設定を捨てたりしません。部分出力と発生済み使用量は無料再試行ではありません。地域・枠・規約を守り、全ルート失敗も考慮してください。

[使用量](/ja/features/quota-tracking/) · [構成](https://github.com/ByKitsune/kitsune-router/blob/master/docs/ARCHITECTURE.md)。無停止、固定削減、絶対的金額上限は保証しません。
