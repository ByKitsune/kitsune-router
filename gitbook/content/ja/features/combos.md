# コンボとフォールバック

コンボは選んだモデルを含む名前付きルートです。アカウント・権限・追加枠を作るものではありません。

## 作成手順

1. 許可された上流を接続し、有効モデルを確認します。
2. ダッシュボードの Combos に固有名（例 `my-route`）を作ります。
3. 正確なモデル ID と対応戦略・順序を選び、全メンバーの能力・権限を確認します。
4. 保存後、コンボ名をクライアントのモデルとして使います。

```json
{
  "model": "my-route",
  "messages": [{ "role": "user", "content": "Hello" }],
  "stream": true
}
```

これは要求例で、DB インポート形式ではありません。先にコンボを作り、循環を避けてください。入れ子では保守的な制限を確認し、最大コンテキスト・ツール対応が全メンバーに共有されると考えないでください。

スポンサーやカテゴリに必須位置はありません。不明な価格・制限は不明のままです。試行は有限で追加課金の可能性があり、連続稼働や金額上限を保証しません。[ルーティング](/ja/features/smart-routing/) · [使用量](/ja/features/quota-tracking/)。[移行](https://github.com/ByKitsune/kitsune-router/blob/master/docs/MIGRATION.md) はコンボを保持します。改名のために DB を空にしないでください。
