# API キーと費用の選択

従来の「低価格」カテゴリは文書上の分類で、優先順位や料金保証ではありません。処理内容・能力・現契約で選びます。

1. 公式手順でキーを取得し、規約・地域を確認します。
2. 正しいエンドポイント・名前空間で対応プロバイダーやノードを登録します。
3. 実モデル・制限を確認します。公開 API、再販、coding plan の ID・価格は同じとは限りません。
4. クライアント用ゲートウェイキーを作り、任意の順でコンボに追加します。

公開 issue・設定例に秘密を入れないでください。非公開の絶対 `DATA_DIR` と完全バックアップを使用します。ローカル保存は全キー暗号化を意味しません。

## 公式 ByKitsune プロバイダー

ByKitsune は主要な公式プロバイダーとして一覧の先頭に表示されます。**Providers** で **Connect ByKitsune** を選び、[ByKitsune のキー管理画面](https://bykitsune.com/dashboard?tab=keys)から取得したキーを追加して、**Fetch Models** を選択します。API ベース URL は `https://api.bykitsune.com/v1`、認証は Bearer です。取得した `bykitsune/<model-id>` ルートを使用してください。アカウントとルーティング順序は引き続き利用者が選択します。

この連携は現在のソースコード向けです。

## 料金の境界

日付・端点・コンテキスト・キャッシュ・媒体・実速度階層で料金が変わります。古い「$0.20/1M」は現請求の証明ではありません。上流請求と確認済みメタデータ・上書きを使い、不明をゼロにしません。

圧縮や再試行で費用は変わり、固定削減・金額上限は保証しません。ByKitsune は保守・支援者で、必須購入先ではありません。[使用量](/ja/features/quota-tracking/) · [コンボ](/ja/features/combos/) · [インストール](/ja/getting-started/installation/)。
