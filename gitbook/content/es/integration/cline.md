# Integración con Cline

Usa el modo OpenAI Compatible de tu versión de Cline; un login nativo puede evitar el gateway. Primero inicia Kitsune Router, conecta un upstream permitido, crea/copia la clave y elige ruta habilitada.

```text
Base URL: http://localhost:20128/v1
API key: clave del gateway emitida
Model ID: modelo habilitado o combo configurado
```

Revisa el preset, conserva ajustes del editor y protege secretos. Proveedor `kitsunerouter`; comando `kitsune-router`.

Prueba una solicitud pequeña y después herramientas/visión requeridas. Catálogo no demuestra permisos ni soporte completo. Compresión no promete ahorro fijo. Respeta plazos 429/503; remoto requiere tu HTTPS autenticado, sin cuenta ByKitsune obligatoria.
