# Integración con Cursor

Usa los ajustes OpenAI-compatible personalizados que admita tu versión de Cursor. No concede una suscripción ni habilita toda función alojada.

Inicia el gateway, conecta un proveedor permitido, crea una clave y elige un modelo/combo desde `/v1/models`.

```text
Base URL: http://localhost:20128/v1
API key: clave del gateway emitida
Model: ID habilitado exacto o combo creado
```

Revisa presets conservando otros ajustes. Identificador de proveedor `kitsunerouter`; ejecutable `kitsune-router`. Las etiquetas de UI pueden cambiar.

Funciones en servidores del editor no alcanzan tu localhost. El acceso remoto requiere tu HTTPS autenticado; no abras el dashboard sin protección. Herramientas, visión y documentos dependen de ruta/cliente. [Otros clientes](/es/integration/other-tools/) · [Diagnóstico](/es/troubleshooting/).
