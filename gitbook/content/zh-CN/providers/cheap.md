# API-key 提供商与成本选择

历史“低价”分类只是文档分组，不是优先级或价格保证。按工作负载、能力和当前合约选择受支持提供商或兼容端点。

## 连接

1. 通过提供商官方流程获取 key，核实条款和地域。
2. 在仪表盘添加支持的提供商/兼容节点，使用正确端点和模型命名空间。
3. 查看实际模型和限制；公开 API、转售商、编程套餐的 ID 与费用不可混用。
4. 为客户端创建网关 key，需要时按你的顺序加入组合。

不要将提供商秘密放进公开 issue 或提交示例。使用私密绝对 `DATA_DIR` 并整目录备份；本地存储不意味着所有 key 已静态加密。

## 费用边界

价格取决于日期、端点、上下文、缓存时长、媒体单位和实际速度档位；陈旧的“每百万 $0.20”不能证明今天的账单。参考上游当前计费、仪表盘元数据及显式覆盖，未知保持未知而非零。

压缩效果因任务而异，回退可能产生额外付费尝试。无固定节省或绝不超支保证。ByKitsune 是维护方/赞助方，不是必购服务。见 [用量](/zh-CN/features/quota-tracking/)、[组合](/zh-CN/features/combos/) 和 [安装](/zh-CN/getting-started/installation/)。
