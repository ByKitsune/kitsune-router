# 智能路由

Kitsune Router 使用**你配置的**模型与账户，不强制“订阅→低价→免费”的顺序，不优先 ByKitsune，也不要求其账户。

## 选择与回退

直接模型请求选择该路由；组合名称展开你配置的成员及策略，然后在相应提供商内选择账户。直接模型不会自动获得无关的全局回退链。

```text
请求 my-route
  → 已配置成员 A → 符合条件的账户
  → 允许的重试/回退
  → 已配置成员 B，或明确的最终错误
```

先创建 `my-route`，按能力、隐私、延迟或成本选择实际启用模型。类别不决定顺序。见 [组合](/zh-CN/features/combos/)。

未知配额不是无限额度。无效请求和取消不应耗尽账户池；回退不能静默提高付费输出上限或丢弃文档/参数。已有部分输出与真实用量不能伪装成免费重试。遵守配额、地域与服务条款；所有成员都可能不可用。

见 [用量](/zh-CN/features/quota-tracking/) 与 [架构](https://github.com/ByKitsune/kitsune-router/blob/master/docs/ARCHITECTURE.md)。没有零停机、固定节省或绝不超支保证。
