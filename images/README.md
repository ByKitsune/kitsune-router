# Kitsune Router artwork and screenshots

- `kitsune-router.png` is a real screenshot of the packaged 1.0.0 candidate's
  dashboard, using a disposable local installation with synthetic data. It is
  not a production account or a claim that 1.0.0 has been published.
- `archive/zenrouter-dashboard-pre-1.0.png` is a historical ZenRouter screenshot,
  preserved unchanged. Do not use it to illustrate the
  current interface.
- `fusion-combo-ui.png` is a historical feature reference; replace it with a
  current capture when documenting that feature, rather than relabeling its
  old contents as a new screenshot.

The current editable product mark and social-card sources live in `public/icons/`
and `public/brand/`. Bitmap icons, favicons and the tray icon are generated from
those SVGs with `scripts/generate-brand-assets.mjs`.
