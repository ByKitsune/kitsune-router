## Reasoning contracts

Visibility and execution are independent. Gemini `includeThoughts`, OpenRouter
`exclude`, and Responses `summary` can specify visibility without selecting an
effort or budget. Responses `summary: null` or `"none"` requests omitted
reasoning; the legacy `generate_summary` alias is retained. Translation must
preserve the visible/hidden choice without changing the caller's output cap.

Claude's thinking configuration is a tagged union. A standalone `display` value
cannot form a valid native request without a mode, and manual enabled thinking
also requires a budget. A display-only translation to Claude therefore fails
locally with `unsupported_parameter`; supply an explicit thinking mode/effort
or use a destination with an independent visibility control. Valid explicit
thinking modes and model suffixes retain their display setting.

Kiro explicit disable overrides a separate effort setting in both native
fields and its prompt prefix. A visibility-only request does not activate
adaptive thinking. Regression tests inspect JSON sent to a loopback HTTP server
through real executors; they do not call a paid provider.

## Codex account fallback

A canonical HTTP 400 ChatGPT-plan denial must name the attempted wire model.
It remains an account/model routing hint, without a credential-health lock,
and does not consume the generic consecutive-systemic-error breaker. A later
eligible account can answer after three denied accounts. Generic systemic
failures retain the breaker and their bounded same-account retries.

The initial active Codex account IDs bound a request's pool. Each retry still
rechecks current rows, activation, credentials and locks; adding new accounts
does not extend an in-flight request. Explicit quota/billing evidence retains
availability cooldowns instead of becoming an entitlement hint.

## Installer and runtime

The original PR's CI failed because installer fixtures replaced `PATH` before
launching a relative `bash` executable. The test harness now resolves an
absolute Bash executable first and retains the isolated subprocess PATH.

Real offline Bun reproduction also exposed repeated global installation failing
with `EEXIST` after a wrapper replaced Bun's package symlink. The installer
temporarily retains only its own marked wrapper, allowing Bun to recreate its
bin, and restores that wrapper if Bun fails before creating a replacement.
Wrappers use mode `0755`; directory and symlink-to-directory destinations are
rejected. The installed package's JavaScript entry remains unchanged.

Source runtime selection requires generated `server.js`, a build ID, the custom
server, and its immediate startup closure. Required entries must be files.
Incomplete source output falls back only to a complete packaged `cli/app`;
otherwise `--check-install` reports rebuild/reinstall guidance. Verification
does not create application state or start a server.
